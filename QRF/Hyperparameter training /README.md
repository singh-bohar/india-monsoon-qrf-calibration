# Hyperparameter Tuning

This repository contains scripts and utilities designed to optimize QRF machine learning model by tuning their hyperparameters across each grid point. Each file serves a distinct purpose in the hyperparameter tuning pipeline. Below is a description of each file and its intended use.

---

## Files and Descriptions

### 1. `Missing Value Investigation.ipynb`
**Description:**  
Investigate the presence of missing/ zero values that affect predictions over Rajasthan.

---

### 2. `Single Grid Calculations + Hyperparameter Tuning.ipynb`
**Description:**  
Single grid calculations to check, and tune hyperparameters to obtain a range of suitable values to start with.

---

### 3. `All_Data_Testing + Hyperparameter Tuning.ipynb`
**Description:**  
Same as 3, but for all the grid points.
